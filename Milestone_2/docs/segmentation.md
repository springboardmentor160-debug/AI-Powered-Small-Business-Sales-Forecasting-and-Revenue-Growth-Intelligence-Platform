# Milestone 2 — Customer Segmentation Documentation

## 1. Overview
Customer Segmentation in Milestone 2 partitions customers into distinct behavioral segments based on historical transaction activity. This allows MarketMind AI to tailor marketing strategies, identify high-value VIP accounts, and trigger win-back campaigns for disengaged customers.

---

## 2. Feature Engineering Pipeline

Source dataset: `Milestone_2/data/source/cleaned_superstore.csv`

### Feature Definitions
1. **Recency (`recency_days`):** Number of days between the latest overall date in the dataset and the customer's most recent order date.
2. **Frequency (`frequency_orders`):** Unique order count per customer.
3. **Monetary Value (`monetary_sales`):** Total cumulative revenue generated by the customer.
4. **Average Order Value (`avg_order_value`):** `monetary_sales / frequency_orders`.
5. **Total Profit (`total_profit`):** Sum of net profit generated from orders.
6. **Average Discount (`avg_discount`):** Average discount percentage received on purchases.

### Preprocessing & Scaling
- Log-transformation (`np.log1p`) applied to right-skewed variables (`monetary_sales`, `frequency_orders`, `avg_order_value`).
- Standardized using `sklearn.preprocessing.StandardScaler`.

---

## 3. Clustering Algorithms & Evaluation

### A. K-Means Clustering
- Evaluated over range $k \in [2, 6]$.
- Best silhouette score achieved at $k = 2$ (**0.2733**).

### B. Hierarchical Agglomerative Clustering
- Evaluated using Ward linkage over range $k \in [2, 6]$.
- Best silhouette score achieved at $k = 2$ (**0.3013**).
